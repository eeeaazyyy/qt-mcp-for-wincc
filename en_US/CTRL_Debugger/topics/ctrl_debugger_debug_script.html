CTRL Debugger - Script Debugging Examples

Normally scripts execute in fractions of a second, so it is often impossible to stop a script quickly enough after starting it with a click. You can, however, set a breakpoint. If you run the script again by using "Continue", it will execute up to the first breakpoint that you have set. In order to see all set breakpoints of a script, update the tree view on the Breakpoints tab. In order to debug a thread, set a breakpoint for a callback function of a script. This way you can debug Threads.

Trend

In the following example you will use the cyclic script of the example panel WinCC_OA_path/panels/examples/trend.

  1. Open the panel in the Vision module and click on Start. Random numbers are set for the datapoint ExampleDP_Trend1 and displayed in a trend.

  2. Open the CTRL Debugger for the manager UI_1 (or for another manager, depending on the manager you use) via the WinCC OA console or via the graphic editor

  3. Click on the "Clicked" event of the panel "trend" in the tree view of the debugger.

  4. Set a breakpoint on the row 28 (dpSet). The script is stopped. The trend curve is continued as a straight line.

  5. Click thereafter on or press F5 in order to continue the script. The trend displays different values and draws a curve.

  6. Click on the breakpoint to delete it and continue the script. The trend displays different values and draws a curve.

  7. Click on to stop the script and on to continue the script. Use F8 for single step.
