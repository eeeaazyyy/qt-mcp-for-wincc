Control functions for SQL

The functions listed comply with the general SQL syntax. For more information about SQL, refer to the relevant literature.

Control functions:

dpQuery() dpQueryConnectAll()
dpQueryConnectSingle() dpQueryDisconnect()

In an SQL query, there should be no line change in the script within dpQuery. This is governed by the SQL syntax.

The abbreviations UI (User Interface), CTRL (Control) and DP (datapoint function or alerting action) indicate where the function concerned is available. Control functions with the character 6 block the execution of a script until a response is received from the Event Manager (see also Control/Availability manual).
